# Date Picker

## Basic Usage

```html
<forge-date-picker>
  <forge-text-field>
    <label for="date-input">Select Date</label>
    <input id="date-input" type="text" placeholder="Select date..." />
  </forge-text-field>
</forge-date-picker>
```

## Notes

- Wraps a `<forge-text-field>` with date selection functionality
- Requires a child `<forge-text-field>` with a labeled input
