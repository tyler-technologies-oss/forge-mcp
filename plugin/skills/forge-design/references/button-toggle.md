# Button Toggle

## Basic Usage

```html
<forge-button-toggle-group>
  <forge-button-toggle value="option1">Option 1</forge-button-toggle>
  <forge-button-toggle value="option2">Option 2</forge-button-toggle>
  <forge-button-toggle value="option3">Option 3</forge-button-toggle>
</forge-button-toggle-group>
```

## Notes

- Must be used within a `<forge-button-toggle-group>`
- Each toggle needs a `value` attribute for identification
- Use for mutually exclusive options (like a segmented control)
