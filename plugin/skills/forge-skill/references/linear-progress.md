# Linear Progress

## Basic Usage

```html
<forge-linear-progress></forge-linear-progress>
<forge-linear-progress determinate progress="0.65"></forge-linear-progress>
```

## Notes

- Default is indeterminate (animated bar)
- Use `determinate` attribute for specific progress display
- Use `progress` attribute with value 0-1 (e.g., 0.65 = 65%)
