# Option Group

## Basic Usage

```html
<forge-option-group label="Group Label">
  <forge-option value="option1">Option 1</forge-option>
  <forge-option value="option2">Option 2</forge-option>
</forge-option-group>
```

## Notes

- Groups related `<forge-option>` elements with a label
- Use `label` attribute for the group heading
- Used within select components for categorized options
