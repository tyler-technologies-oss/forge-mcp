# Chip

## Basic Usage

```html
<forge-chip-set>
  <forge-chip>Basic Chip</forge-chip>
  <forge-chip>Deletable Chip</forge-chip>
  <forge-chip>
    <forge-icon name="person" slot="start"></forge-icon>
    Chip with Icon
  </forge-chip>
</forge-chip-set>
```

## Notes

- Should be used within a `<forge-chip-set>` container
- Use the `start` slot for leading icons
- Text content goes in the default slot
