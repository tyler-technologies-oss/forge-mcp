# Icon

## Basic Usage

```html
<forge-icon name="home"></forge-icon>

<!-- Use external if you need to load the icon dynamically -->
<forge-icon name="settings" external></forge-icon>
```

## Notes

- Use `name` attribute to specify the icon from the Tyler Icons library
- Use `external` attribute to load icons dynamically (when not pre-registered)
- Icons are typically used within buttons, list items, and other components
