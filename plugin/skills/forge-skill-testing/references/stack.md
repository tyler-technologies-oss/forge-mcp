# Stack

## Basic Usage

```html
<!-- Use the stack component SPARINGLY for situations that need it. DO NOT OVERUSE FOR GENERAL LAYOUT PURPOSES. -->
<forge-stack inline>
  <forge-button>Button 1</forge-button>
  <forge-button>Button 2</forge-button>
  <forge-button>Button 3</forge-button>
</forge-stack>
```

## Notes

- **Use SPARINGLY** - Only for specific layout situations
- **Do NOT use for general layout purposes** - Prefer CSS flexbox/grid utilities
- Use `inline` attribute for horizontal stacking
- Default is vertical stacking
