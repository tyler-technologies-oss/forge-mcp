# Button Toggle Group

## Basic Usage

```html
<forge-button-toggle-group>
  <forge-button-toggle value="left">Left</forge-button-toggle>
  <forge-button-toggle value="center">Center</forge-button-toggle>
  <forge-button-toggle value="right">Right</forge-button-toggle>
</forge-button-toggle-group>
```

## Notes

- Container for `<forge-button-toggle>` elements
- Manages selection state across child toggles
- Only one toggle can be selected at a time by default
