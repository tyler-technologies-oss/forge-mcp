# Stepper

## Basic Usage

```html
<forge-stepper>
  <forge-step>Step 1</forge-step>
  <forge-step>Step 2</forge-step>
  <forge-step>Step 3</forge-step>
</forge-stepper>
```

## Notes

- Container for `<forge-step>` elements
- Displays progress through a multi-step process
- Control the active step programmatically
