# List Patterns

Reference for Forge list components.

---

## List Item Slots

| Slot | Purpose |
|------|---------|
| `start` | Leading content (icons) |
| `trailing` | Trailing content (actions, badges) |
| (default) | Main content |

---

## Navigation List Attributes

| Attribute | Purpose |
|-----------|---------|
| `navlist` | Marks the list as navigation |
| `selected` | Marks a list item as selected |

---

## List Rules

1. Use `navlist` attribute on navigation lists
2. Use `<forge-divider>` between list sections
3. All action icon buttons need `aria-label`
