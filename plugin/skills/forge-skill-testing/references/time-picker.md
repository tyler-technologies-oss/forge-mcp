# Time Picker

## Basic Usage

```html
<forge-time-picker>
  <forge-text-field>
    <label for="time-picker-input">Choose time</label>
    <input type="text" id="time-picker-input" />
  </forge-text-field>
</forge-time-picker>
```

## Notes

- Wraps a `<forge-text-field>` with time selection functionality
- Requires a child `<forge-text-field>` with a labeled input
