# Badge

## Basic Usage

```html
<forge-badge>5</forge-badge>
<forge-badge dot></forge-badge>
<forge-badge theme="success">New</forge-badge>
```

## Notes

- Use text content for count or label badges
- Use `dot` attribute for a simple indicator without text
- Use `theme` attribute for semantic coloring (e.g., "success", "warning", "error", "info")
