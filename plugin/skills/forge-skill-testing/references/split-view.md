# Split View

## Basic Usage

```html
<forge-split-view>
  <forge-split-view-panel>
    <div>Panel 1 Content</div>
  </forge-split-view-panel>
  <forge-split-view-panel>
    <div>Panel 2 Content</div>
  </forge-split-view-panel>
</forge-split-view>
```

## Notes

- Creates resizable split panes
- Uses `<forge-split-view-panel>` children for each panel
- Supports horizontal and vertical orientations
