# Label Value

## Basic Usage

```html
<forge-label-value>
  <span slot="label">Name</span>
  <span slot="value">John Doe</span>
</forge-label-value>
```

## Notes

- Displays a label/value pair in a consistent format
- Use `label` slot for the label text
- Use `value` slot for the value content
- Good for read-only data display
