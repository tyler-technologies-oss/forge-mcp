# Dialog Rules

Dialogs use `<forge-scaffold>` for proper layout with header, body, and footer regions.

---

## Rules

1. **Use `aria-labelledby` on dialogs** pointing to the title element
2. **Close button must have `aria-label="Close dialog"`**
3. **Dialog titles use `text-heading3`** (same as card headers)
4. **Body content uses `p-medium` padding**

---

Use the MCP tools to get the latest component API details for dialog and scaffold components, including available slots and attributes.
