# Skeleton

## Basic Usage

```html
<forge-skeleton avatar></forge-skeleton>
<forge-skeleton text></forge-skeleton>
<forge-skeleton text></forge-skeleton>
<forge-skeleton text style="width: 75%;"></forge-skeleton>
```

## Notes

- Loading placeholder component
- Use `avatar` attribute for circular avatar placeholder
- Use `text` attribute for text line placeholder
- Adjust width inline for varied line lengths
- Combine multiple skeletons to match expected content layout
